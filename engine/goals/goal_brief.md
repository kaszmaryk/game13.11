# Цели игры: Врачи против правительства (Англия, май 2026)

## Общая цель

Симуляция переговоров между резидент-врачами NHS и правительством Великобритании
в период с 27 мая по 5 июля 2026 года. Игроки управляют одним из шести органов
и пытаются достичь своих целей в условиях трёх «замков» сделки.

## Три замка сделки

1. **Забастовочный замок** — мандат, уведомление, календарь, стоимость каждого дня.
2. **Ратификационный замок** — референдум членов BMA, простое большинство.
3. **Фискальный якорь** — DDRB 3,5% + лимит Казначейства.

## Условия победы

Для каждого органа:
- **≥70%** суммы весов выполненных целей = Победа
- **40–69%** = Частичный успех
- **<40%** = Поражение (даже если сделка принята)

## Органы и их главные цели

| Орган | Главная цель | Вес |
|-------|-------------|-----|
| RDC | Сделка принята базой с pay+jobs | 50% |
| BMA Council | Единство союза across branches | 40% |
| DHSC | Закончить забастовки без слома лимита | 45% |
| HMT | Удержать лимит | 50% |
| Providers | Безопасность пациентов / staffing | 40% |
| AoMRC | Качество и число мест ординатуры | 40% |

## Ключевые вопросы для игроков

1. Как добиться pay restoration, не нарушив бюджетный лимит?
2. Как сохранить единство базы при разных интересах грейдов?
3. Как остановить забастовки, не спровоцировав заражение госсектора?
4. Как обеспечить безопасность пациентов во время забастовок?
5. Как использовать структурные реформы (места, сборы) как альтернативу повышению ставок?
