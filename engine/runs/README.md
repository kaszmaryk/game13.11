# Runs

Эта директория содержит результаты игровых сессий.

Каждая сессия сохраняется в отдельной поддиректории с именем `run_YYYYMMDD_HHMMSS/`.

## Структура сессии

```
run_20260527_140000/
├── turn_01_input.json      # Входные данные раунда 1
├── turn_01_agents.json     # Решения агентов раунда 1
├── turn_01_output.json     # Выход движка раунда 1
├── turn_02_input.json
├── ...
└── final_state.json        # Финальное состояние игры
```
